# PrismaTI

Estrutura inicial do backend em Python com Flask, organizada em Clean Architecture.

A API inclui autenticação, convites, recuperação de senha, avaliações, cálculo de maturidade, evidências, auditoria e relatórios com exportação em PDF. Consulte [execução, configuração dos provedores e endpoints](docs/api.md).

Consulte [a arquitetura do projeto](docs/arquitetura.md) para entender as responsabilidades, dependências e o fluxo de execução planejado.

As pastas vazias usam `.gitkeep` para preservar a estrutura no controle de versão. Os nomes estão em inglês para o código; a documentação está em português.
